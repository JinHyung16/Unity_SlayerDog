# 2026-08-26 — 2D 뱀서류 전환 구현

## 확정
장르는 **2D 뱀서류**. 넓은 필드 파밍은 폐기하되 파츠 시스템은 유지(3택1 대신 필드 드랍 상자).
- 월드는 XZ 평면 유지, 카메라만 오쏘그래픽 쿼터뷰(pitch 50°, orthoSize 8.85) + 스프라이트 빌보드
  → 충돌·타겟팅·발사 로직을 하나도 안 고치고 룩만 2D 가 됐다
- PPU 32 (64px = 2유닛). 기존 휴머노이드 스케일(캐릭터 ~1.8유닛)과 그대로 맞는다

  부위를 레이어로 나눠 각각 팽창시켜야 팔/다리 분리선이 생긴다 (1차는 실루엣 하나만 씌워 팔다리가 묻혔다)
- PNG 231개의 `.meta` 직접 생성. GUID 는 경로 md5 로 고정 — 재실행해도 참조가 안 끊긴다

### DB
- `tools/gen_parts.js` 스펙 표 하나로 스킬 27 / 파츠 27 / 옵션 105 / 적 5 / 웨이브 2 생성
- enum `EPartSlot`·`EPartTrait`, config 에 `part`·`option` 모듈 + `enemy.Sprite` 컬럼, `augment` 모듈 제거

### 엔진 — 1순위 3개 전부 구현
- **`SkillModifier`** — 파츠 옵션이 「이 스킬만」 보정. 적용점은 `SkillNodeData.GetFloat/GetInt` **한 곳뿐**이고,
  공유물인 노드 데이터에 값을 굽지 않고 조회 시 곱해서 내보낸다. 발사체는 `SkillConfig` 가 보정을 들고 있어
  날아가는 중에 파츠를 바꿔도 그 탄은 안 변한다
- **파츠 인스턴스** — 같은 파츠라도 개체마다 옵션이 다르므로 원형(PartData)과 인스턴스 분리
- **부위 6칸 장착/교체** — `PartLoadout`
