# 2026-08-24 — 「개많이잡아」 기획 · 장르 전환

## 확정
### 게임 정체성
- 게임명 `개많이잡아`. 세계관 Dog-World / God-사료 / 개쌘놈(슈퍼독) vs 외계인
- 증강 1개 = 특성 1개(복합 금지). 특성 7종 + 스킬 고유 1종
- 스킬 20종(공용) + 캐릭터 고유 3종. 증강 총 90종
- 아웃게임 카드 레벨 Lv15, `기본값 × (1 + 0.08×(Lv-1))`. 적용 순서 `카드레벨 → 증강 중첩`
- `스킬 피해 = 공격력 × 계수% × 치명타 배수`, `실쿨 = 기본쿨 ÷ (1 + 공속%)`. 적 방어력 없음

### 장르 전환 (같은 날 오후)
뱀서류 3택1 폐기 → **2D 탑다운 12분 파밍 로그라이크**. 이유는 「3택1은 성장이 안 보인다」

| 기존 | 새 구조 |
|---|---|
| 레벨업 3택1 증강 | 파츠 착용 (필드 드랍) |
| 스킬 슬롯 4 | 부위 6칸 (입·발·꼬리·머리·목·등) × 4종 = 공용 24 |
| 무한 평면 스폰 | 200×200 맵 + 배회 + 파밍 포인트 |
| 3D 퍼스펙티브 | 2D 스프라이트 · 오쏘그래픽 |
| 레벨업 = 선택 | 레벨업 = 자동 스탯 (체력 +4% / 공격력 +2% per Lv) |

- 파츠는 **런 한정**. 등급 = 옵션 슬롯 수(일반1/희귀2/전설3)
- 캐릭터 고유 파츠가 부위 하나를 잠근다 (시바=목, 코기=꼬리, 그레이하운드=발)
- 세션 12분. 맵 1장 고정, 파밍 포인트 위치만 랜덤. 12분에 보스 「납치선」

## 실측
없음. 아래는 전부 **계산 검산**이다.
- 10마리 처치 시간이 12분 내내 1.0~1.4초로 평평 (0분만 2.5초 — 알몸 시작 압박)
- 보스 HP 45,000: 카드 Lv1 균형 빌드 71초 / Lv15 34초
- 빌드별 보스 소요: 광역 몰빵 118초 / 균형 71초 / 단일 몰빵 50초

## 발견
- **광역/단일 트레이드오프가 이 게임의 유일한 빌드 압박이다.** 파밍은 광역, 보스는 단일.
  이게 없으면 파츠 선택이 「좋은 거 먹기」로 퇴화한다 — 보스 HP 를 쉽게 내리면 안 된다
- **레벨업 수치를 키우면 게임이 죽는다.** 공격력 +2%/Lv 이상이면 레벨이 주 성장축이 되어 파밍 동기가 사라진다
- 0~2분이 가장 위험 (알몸 + 기본 물기). 시작 지점 근처 택배 상자 1개 보장 배치 필요
- 엔진 1순위 3개: `ModifySkill` / 파츠 인스턴스 개념 / 부위 6칸 장착·교체
- 성능이 밸런스보다 먼저 걸린다 — 12분 목표 120마리는 08-22 실측(49마리 FPS 49)의 2.4배
- 2D 전환 비용은 로직 쪽 거의 0 (충돌이 이미 XZ 2D). 아트는 전량 재제작이나 Free Stickman 이 임시라 순증 아님
- 파츠 장착 표현에 **부위별 피벗 좌표 6종 규격**이 선행 필요
