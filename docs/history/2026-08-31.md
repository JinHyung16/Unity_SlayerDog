# 2026-08-31 — 시너지 3층 · 생존 축 · 12라운드 완주 · 보스/클리어 · 사운드

## 확정
- 시너지 3층 = **연계**. 상태이상을 *거는* 스킬과 *때리는* 스킬이 갈려야 조합이 생긴다
- 성장 축의 절반은 **생존**이다. 전부 공격이면 12분을 버틸 방법이 없다
- 흡혈은 전 계열 공통. 계열마다 생존 1종만 주면 흡혈 없는 계열이 최대 체력만 얻어 곡선이 짧아진다
- 회복은 **최대 체력 비례 초당 상한**으로 묶는다. 처치당 고정 회복은 후반에 처치 수와 함께 폭발한다
- 보스는 잡졸 추첨에서 빼고 타입을 고정한다

## 산출
- `SynergyRegistry.Collect` 에 연계 조건 판정. 연계는 특성이 아니라 **대상 조건부 배수**(`VsDebuff`/`VsDebuffDamageMul`)
- 특성 3종 `MaxHp`/`Lifesteal`/`MoveSpeed` — 스킬별 보정이 아니라 **몸에 한 번만**(`PartLoadout.ApplyBodyTraits`)
- `LifestealCapPerSecond` 신설
- 하네스에 **회피** 도입 — 목표 방향 + 근접 적 반발 벡터 합성(`Steer`)
- `WaveEvent.IsBoss` / `EnemyTypeId` 열 신설. 보스 처치 → `GameFlow.ClearGame()` → 결과 화면 `CLEAR!`
- **자동 조준**(`AutoAim`) — 루트 회전만 돌려 그림(빌보드)과 판정 방향을 분리
- 4방향 스프라이트(정면/뒤/옆 3벌 + 좌우 반전), 월드 HP 바 빌보드, FX 풀 사전 생성
- 사운드: `build_sfx.py` 로 WAV 8종 **절차 생성**. `SfxManager` 가 소스 12개를 돌려 쓰고 최소 간격을 둔다

## 발견
- **하네스가 회피를 안 하고 있었다 — 실측 전체의 전제가 틀려 있었다.** 「가장 가까운 아이템으로 직진」만 했고,
  젬은 적 시체 위에 떨어지므로 매번 적 무리 한가운데로 걸어 들어가는 조작이었다 (함정 34)
- **회복 없는 생존 스탯은 공격을 희석한 만큼도 못 돌려준다** (함정 35)
- `boss: 1` 을 bool 열에 넣어 `AsBool()` 이 조용히 false 를 돌려줬다. 보스는 **스폰돼 있었고** 표식만 안 붙었다 (함정 36)
- 보스가 가중치 추첨으로 나와 매판 다른 몸이었다 (체력 4배차) (함정 37)
- 잡졸 142마리 속에서 100초에 보스 체력 1% — 타겟팅이 「가장 가까운 적」이라 딜이 전부 잡졸로 간다.
  11라운드 상한을 100 으로 낮추고 12라운드 스폰을 사실상 멈춘 뒤 보스 체력을 8,640 으로
- **사운드의 한계**: 소리가 *어떻게 들리는지*는 검증 못 했다. 배선과 재생 횟수만 확인한 자리 채움 음원이다
